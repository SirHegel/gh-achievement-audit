# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Use
[GitHub private vulnerability reporting](https://github.com/SirHegel/gh-achievement-audit/security/advisories/new).
Do not open a public issue containing tokens, private repository details, exploit steps, or
personal data.

The same private form accepts project conduct reports whose title begins with `[Conduct]`.
Those reports are handled as confidential community matters, not as claims that the software
has a vulnerability.

This extension never needs a token outside the authentication already managed by GitHub
CLI. A report that requests users to paste a token, weaken GitHub authentication, or run a
write-capable mutation should be treated as suspicious.
