# Support

Use GitHub Discussions for public usage questions and integration design. Use the issue
templates for reproducible bugs and bounded feature requests. Report vulnerabilities only
through the private route in [SECURITY.md](SECURITY.md).

Include the extension version, Python version, GitHub CLI version, exit code, and a redacted
copy of output. Never include tokens, private repository names, private event details, or
raw API responses from repositories that other people cannot access.
